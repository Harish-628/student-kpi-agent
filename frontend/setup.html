📋 System Overview

The Student KPI Management System is a comprehensive web-based platform designed to track and analyze student performance through Key Performance Indicators (KPIs).

Key Characteristics:

  • Modern, responsive UI with professional design
  • Role-based authentication (4 distinct roles)
  • Real-time data visualization with charts
  • Mobile-friendly interface
  • Easy integration with FastAPI backend
  • Comprehensive student and KPI management

🔗 Backend Integration

API Endpoints Access

The frontend is designed to communicate with your FastAPI backend. Update API URLs in js/dashboard.js:

// Example API configuration const API_BASE_URL = 'http://localhost:8000/api'; // Example: Add Student fetch(`${API_BASE_URL}/student/add`, { method: 'POST', headers: { 'Content-Type': 'application/json', }, body: JSON.stringify({ student_id: 'STU001', name: 'John Doe', department: 'CSE', section: 'A', year: 3 }) })

Enable CORS in FastAPI

Add CORS middleware to your backend/main.py:

from fastapi.middleware.cors import CORSMiddleware app.add_middleware( CORSMiddleware, allow_origins=["http://localhost:8080", "http://localhost:3000"], allow_credentials=True, allow_methods=["*"], allow_headers=["*"], )
ℹ️ Note: Currently, the frontend uses demo data. To connect to your backend, you'll need to:
  • Update fetch URLs in JavaScript files
  • Implement proper authentication tokens
  • Handle API responses and errors
  • Store session tokens securely

🎨 Customization Guide

Edit CSS variables in css/styles.css:

:root { --primary-color: #6366f1; /* Change primary color */ --primary-dark: #4f46e5; --secondary-color: #8b5cf6; /* Change secondary color */ --success-color: #10b981; /* Change success color */ /* ... modify other colors ... */ }

Add New Navigation Items

In js/dashboard.js, modify the setupNavigation() method:

const menuItems = { newFeature: { icon: '🆕', label: 'New Feature', section: 'new-feature' }, // ... add more items };

Modify KPI Categories

Edit the KPI input form in dashboard.html to add or remove categories.

Customize Dashboard Cards

Update KPI card data in js/dashboard.js populateKPICards() method.

🔧 Troubleshooting

Login Issues

Problem: Cannot log in

Solutions:

  • Clear browser cache and cookies
  • Check that JavaScript is enabled
  • Verify using correct demo credentials
  • Check browser console (F12) for errors
  • Ensure localStorage is enabled

Charts Not Displaying

Problem: Charts appear blank or missing

Solutions:

  • Verify Chart.js library is loaded
  • Check for JavaScript errors in console
  • Ensure canvas elements exist in HTML
  • Check that chart data is properly formatted

Sidebar Not Responsive

Problem: Sidebar doesn't collapse on mobile

Solutions:

  • Clear CSS cache
  • Check viewport meta tag in HTML
  • Verify media query breakpoints
  • Inspect toggle button click events
⚠️ Important Security Notes:
  • Development Only: The current authentication is for demo purposes only
  • Production Deployment: Implement proper JWT authentication
  • HTTPS Required: Always use HTTPS in production
  • Secure Storage: Never store sensitive data in localStorage
  • Input Validation: Validate all user inputs on backend
  • CORS Configuration: Restrict origins appropriately for production
